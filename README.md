<summary>Run this portfolio locally</summary>

The personal link index lives at `/`. The existing portfolio lives at `/studio`, with its pages under `/studio/about`, `/studio/projects`, `/studio/services`, and `/studio/contact`. Previous page URLs redirect to their new locations.

```bash
npm install
npm run dev
```

```bash
npm run lint
npm run typecheck
npm run build
```

The production build generates the personal homepage and all `/studio` pages, including complete case-study HTML. It also verifies page output, assets, canonicals, the sitemap, and redirects that preserve query strings and anchors.

```bash
npm run deploy
```

Deployment rebuilds and verifies the site before publishing `dist` to the `gh-pages` branch. The custom domain and `.nojekyll` marker are included.
